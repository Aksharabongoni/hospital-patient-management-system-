# 🏥 Hospital Patient Management System

### Data Cleaning | Data Analysis | Data Visualization | Power BI Dashboard

## 📌 Project Overview

The **Hospital Patient Management System** is a data analytics project developed to process, clean, analyze, and visualize hospital patient records.

The project focuses on transforming raw hospital data into meaningful insights using Python, Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook, and Microsoft Power BI.

It helps understand patient admissions, discharges, department-wise performance, patient demographics, hospital revenue, and other important healthcare indicators through data analysis and interactive dashboards.

The main goal is to improve healthcare data management and support data-driven decision-making.

---

## 🎯 Project Objectives

- Collect and organize hospital patient records.
- Identify and handle missing values and duplicate records.
- Clean and preprocess raw hospital datasets.
- Perform Exploratory Data Analysis (EDA).
- Analyze patient admission and discharge patterns.
- Identify department-wise patient trends.
- Generate meaningful charts and visualizations.
- Develop an interactive Power BI dashboard.
- Present useful insights to support hospital management decisions.

## 🚀 Getting Started

Follow these instructions to run the project on your local machine.

### 1. Clone the Repository

```bash
git clone https://github.com/Aksharabongoni/hospital-patient-management-system-.git
```

### 2. Navigate to the Project Folder

```bash
cd hospital-patient-management-system-
```

### 3. Create a Virtual Environment (Recommended)

```bash
python -m venv venv
```

Activate the environment on Windows:

```bash
venv\Scripts\activate
```

### 4. Install Required Libraries

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

### 5. Run the Data Cleaning Script

```bash
python data_cleaning.py
```

### 6. Run the Data Analysis Script

```bash
python Data_analysis.py
```

### 7. Run the Data Visualization Script

```bash
python Data_visualisation.py
```

### 8. Open the Power BI Dashboard

Open `Dashboard.pbix` using Microsoft Power BI Desktop.

**Important:** Ensure the dataset paths in the Python scripts match the actual location of your CSV files. Run the scripts from the appropriate project directory.
